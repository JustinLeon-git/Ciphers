##Overview##
A small C++ project that allows a user to decrypt and encrypt Caesar ciphers and substitution ciphers when given arbitrary text input. The program also allows for text files as input, enabling the user to decrypt or encrypt text en masse. For the substitution cipher, I've implemented a hill climbing algorithm using quadgrams to more efficiently deduce the correct decryption key from a given text encrypted by a substitution cipher. There are also unit tests implemented using Google Test, which I use with a makefile to compile and test the encryption and decryption functionality.
